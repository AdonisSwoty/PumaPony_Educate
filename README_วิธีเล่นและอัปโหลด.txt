พี่พูม่า & น้องโพนี่ : ผจญภัยเกาะมหัศจรรย์ V3
=================================================

เล่นได้จริง 7 ดินแดน
1. ป่าสีลูกกวาด: เลือกสีและสังเกต
2. สะพานตัวเลข: เติมตัวเลขในลำดับ
3. หุบเขา ABC: ศัพท์อังกฤษและฟังการออกเสียง
4. วิหารรูปทรง: เลือกรูปทรงให้ถูกต้อง
5. ถ้ำคริสตัล: พลิกการ์ดจับคู่ฝึกความจำ
6. เขาวงกตกุญแจ: ใช้ลูกศรเดินเก็บกุญแจและเข้าประตู
7. ปราสาทดวงดาว: คำถามผสมไขปริศนา

ตัวละคร: พี่พูม่า = เสือ 🐯 | น้องโพนี่ = ม้าโพนี่ 🐴

วิธีเปิดเล่น
- คอมพิวเตอร์: เปิดไฟล์ index.html ใน Chrome/Edge/Safari
- โทรศัพท์: แนะนำให้เปิดผ่าน GitHub Pages ด้วย Safari หรือ Chrome
  (การเปิดไฟล์ .html ภายในหน้าพรีวิวของแอปแชทอาจไม่แสดง JavaScript)

วิธีขึ้น GitHub Pages (ไม่ต้องติดตั้งแพ็กเกจ)
1) สร้าง repository ใหม่ใน GitHub เช่น puma-pony-adventure
2) อัปโหลดไฟล์ index.html จาก ZIP ไปที่ root ของ repository
3) ไปที่ Settings > Pages
4) เลือก Build and deployment > Deploy from a branch
5) เลือก branch main และ folder /(root) แล้ว Save
6) รอ GitHub สร้างลิงก์ แล้วเปิดลิงก์จาก Safari บน iPhone

ไม่มีการเรียก API หรือเก็บข้อมูลเด็กผ่านเซิร์ฟเวอร์
คะแนนและด่านที่ผ่านบันทึกด้วย localStorage เฉพาะในเบราว์เซอร์
สามารถกดเริ่มใหม่เพื่อรีเซ็ตความคืบหน้า
ระบบเสียงออกเสียงขึ้นกับเสียง/ภาษาที่เบราว์เซอร์ของอุปกรณ์รองรับ

หมายเหตุ: ฉากเป็นภาพจำลอง 2.5D ไม่ใช่เกม 3D ที่เดินในโลกอิสระ
