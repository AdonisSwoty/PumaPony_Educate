เกาะมหัศจรรย์ — เกมคู่หูพี่น้อง (เว็บต้นแบบ)

วิธีเล่น
1. เปิดไฟล์ rainbow_island_kids_game.html ด้วย Chrome, Safari หรือ Edge
2. เลือก 1 ใน 3 เกมบนหน้าจอหลัก
3. น้องอายุ 3–5 ขวบเล่นตาแรก พี่อายุ 7–8 ขวบเล่นตาที่สอง
4. ช่วยกันผ่านเกมละ 3 ด่านและเก็บดาว

เกมที่มี
• สวนสีสายรุ้ง: แยกสีและนับจำนวน
• เพื่อนสัตว์หิวแล้ว: สังเกตสัตว์และจับคู่อาหาร
• ปราสาทรูปทรง: ระบุรูปทรงและต่อแบบรูป

คุณสมบัติ
• เว็บ HTML ไฟล์เดียว ไม่ต้องติดตั้งหรือต่ออินเทอร์เน็ต
• หน้าตา 3D-style จาก CSS (ไม่ใช่โมเดล 3D หมุนได้)
• รองรับจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์
• ไม่มีโฆษณา ไม่มีบัญชีผู้ใช้ ไม่มีระบบติดตาม
• ดาวถูกบันทึกไว้เฉพาะบนเบราว์เซอร์เครื่องนั้น (หากเบราว์เซอร์อนุญาต)
• ปุ่มฟังคำใบ้: ใช้ระบบอ่านข้อความของเบราว์เซอร์ หากมีภาษาไทยรองรับ
• ไม่จำกัดเวลา ตอบผิดได้โดยไม่หักคะแนน

ถ้าจะเปิดให้ทั้งครอบครัวผ่านลิงก์ แชร์ไฟล์ .html ขึ้น Cloudflare Pages, GitHub Pages หรือโฮสต์เว็บไซต์แบบ Static ได้
